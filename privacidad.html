Política de privacidad

Vigente desde el 28 de septiembre de 2026.

A quién aplica

inbox-tools es una herramienta de uso personal que accede a una sola cuenta de Google, la de su propio dueño. No recolecta datos de otras personas usuarias porque no tiene otras personas usuarias.

Qué datos de Google usa y para qué

  • Gmail: lee los mensajes de la cuenta para clasificarlos por tema, resumirlos y detectar pedidos y compromisos, y modifica sus etiquetas (por ejemplo, para marcar el cliente o el tipo de mensaje). No envía, responde, reenvía ni borra mensajes.
  • Google Calendar: lee, sin modificar, los eventos del calendario de trabajo para armar la agenda del día. No crea, edita ni borra eventos.

Dónde se guardan y con quién se comparten

  • Los datos derivados (clasificación, resúmenes, etiquetas, agenda) se guardan en un servidor privado del dueño, sin acceso público.
  • Para generar resúmenes, el texto de algunos mensajes se envía a la API de un proveedor de modelos de lenguaje (Anthropic), que no lo usa para entrenar modelos. Antes de enviarlo se quitan credenciales y datos sensibles.
  • Los datos no se venden, no se usan para publicidad y no se comparten con terceros fuera de lo indicado.
  • No se guardan contraseñas, tokens ni credenciales dentro de los datos procesados.

Uso limitado

El uso y la transferencia de información recibida de las API de Google se ajustan a la Política de datos del usuario de los servicios de las API de Google, incluidos los requisitos de Uso limitado (Limited Use).

Conservación y baja

Los datos se conservan mientras la herramienta esté en uso. El acceso se puede revocar en cualquier momento desde myaccount.google.com/permissions; al revocarlo, la herramienta deja de leer la cuenta y los datos derivados se pueden borrar a pedido.

Summary (English): inbox-tools is a personal tool that accesses only its owner's Google account. It reads and labels Gmail messages and reads (never modifies) calendar events. Derived data is stored on the owner's private server; some message text is sent to Anthropic's API to produce summaries. Data is never sold, used for ads or shared beyond this. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
